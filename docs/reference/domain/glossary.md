# Glossaire métier

| Terme | Définition |
|---|---|
| Domaine | Premier niveau du référentiel de compétences. |
| Sous-domaine | Deuxième niveau, rattaché à un domaine. |
| Compétence | Élément du référentiel rattaché à un sous-domaine ; unité de correspondance profils-formations. |
| Profil d'emploi | Fonction caractérisée par des exigences de compétences. |
| Classification | Catégorie configurable qui qualifie une exigence de profil. |
| Exigence de compétence | Association entre un profil, une compétence et une classification. |
| Formation | Offre pédagogique du catalogue, indépendante de ses sessions. |
| Session | Organisation concrète d'une formation, constituée d'un ou plusieurs créneaux. |
| Créneau | Intervalle daté rattaché à une session. |
| Intervenant | Personne affectée à une session ; compte habilité facultatif. |
| Collaborateur | Fiche minimale de personne utilisée pour suivre ses participations ; aucun lien au profil d'emploi dans le MVP. |
| Participation | Lien unique entre un collaborateur et une session, avec un état courant. |
| Désistement | Retrait d'une inscription sans effacer la participation ; une réinscription réactive cette même participation. |
| Audit | Historique des modifications sensibles, avec auteur, date et valeurs concernées. |

Pour les définitions détaillées, consulter le [glossaire fonctionnel de la baseline](../../functional-baseline-v1.0/reference/glossaire.md).
