## Concepts

| Terme | Définition |
|---|---|
| Domaine | Premier niveau de regroupement des compétences |
| Sous-domaine | Deuxième niveau ; appartient à un domaine |
| Compétence | Capacité professionnelle élémentaire du référentiel |
| Profil d'emploi | Fonction ou métier caractérisé par ses exigences de compétences |
| Classification | Catégorie configurable de l'exigence d'une compétence pour un profil |
| Exigence | Association profil-compétence-classification |
| Formation | Offre du catalogue, indépendante de son calendrier de réalisation |
| Session | Organisation concrète d'une formation |
| Créneau | Intervalle daté de la session |
| Intervenant | Personne affectée à l'animation d'une session, avec compte utilisateur facultatif |
| Collaborateur | Personne référencée pour le suivi de ses participations |
| Participation | Lien unique collaborateur-session avec un état courant |
| Désistement | Retrait d'une inscription, sans effacement de la participation |
| Audit | Historique des modifications sensibles avec auteur, date et valeurs concernées |
| Baseline | Version de référence des exigences à partir de laquelle les changements sont tracés |
